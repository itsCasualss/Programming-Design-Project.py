### Vosk Speech Recognition Setup

1. Download [vosk-model-small-en-us-0.15](https://alphacephei.com/vosk/models)    Direct ZIP Download: [vosk-model-small-en-us-0.15](https://alphacephei.com/vosk/models/vosk-model-small-en-us-0.15.zip)
2. Extract the downloaded ZIP file.
3. Place the extracted folder in `assets/models/`.
4. Verify that the final path is `assets/models/vosk-model-small-en-us-0.15/`.

The speech-recognition model is excluded from GitHub because of its size of >25MB. Each developer must download it locally before running `speech_recognition.py`.
